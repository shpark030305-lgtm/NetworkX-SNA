# 독파모 참여기관의 검증된 기술협력 네트워크 분석

DARPA형 자율적 컨소시엄 구성 아래에서 독파모 참여기관들이 어떤 기술협력 관계를 형성하고 있는지, 선정 이전과 이후에 관측되는 네트워크 구조가 어떻게 다른지 분석합니다.

본 프로젝트의 분석 대상은 **컨소시엄 명단이 아니라 공개자료에 근거한 검증된 기관쌍 협력관계**입니다.

## 데이터

분석에는 다음 세 CSV만 사용합니다. 외부기관도 기관 목록에 포함되어 있으면 분석 대상에 포함합니다.

| 파일 | 내용 |
|---|---|
| `data/기관_목록.csv` | 기관 ID, 기관명, 유형, 팀 소속, 주관기관·다중 팀 여부 |
| `data/검증된_기관쌍_협력관계.csv` | 직접 협업 근거가 있는 기관쌍별 관계 기록 |
| `data/협력관계_출처.csv` | 관계 기록의 출처 ID, 제목, 발행기관, 날짜, URL |

현재 데이터는 기관 **56개**, 관계 기록 **58개**, 출처 ID **32개**로 구성됩니다.

## 네트워크 구성 원칙

- 기관을 노드로 하는 **일원모드 무방향 가중 네트워크**를 구성합니다.
- CSV에 없는 연결은 생성하지 않습니다.
- 동일 컨소시엄 소속이나 다자행사 참가만으로 기관 간 연결을 생성하지 않습니다.
- 같은 기관쌍의 복수 관계 기록은 하나의 edge로 합칩니다.
- edge의 가중치는 해당 기간의 **관계 기록 수**입니다.
- 기관 목록의 모든 기관을 유지하여 고립기관도 분석에 포함합니다.

### 기간 구분

| 구분 | 기준 |
|---|---|
| `pre` | 2025년 8월 4일 이전 |
| `during` | 2025년 8월 4일 당일 및 이후 |
| `all` | 전체 관측 기간 |

기간은 관계 기록의 날짜로 구분합니다. 이는 협력의 실제 시작·종료일을 확정하는 기준이 아닙니다.

### 근거 수준

| 수준 | 정의 |
|---|---|
| `3` | 직접 공동개발·공동연구·실증이 명시된 강한 근거 |
| `2` | 구체적 역할협업이 확인된 중간 근거 |

기본 분석은 수준 2와 3을 사용하고, 엄격 민감도 분석은 수준 3만 사용합니다.

## 분석 내용

- 데이터 구조, ID, 참조 무결성, 날짜·기간 일치 검증
- pre / during / all 네트워크 비교
- degree, weighted degree, betweenness, closeness, density, components, clustering 계산
- 주관기관 중심성 및 비주관기관 간 수평적 관계 분석
- 다중 팀 기관의 중개 위치 분석
- 팀별 유도 부분그래프 및 관계 유형별 네트워크 분석
- 수준 3 근거만 사용한 엄격 민감도 분석
- Walktrap 군집 탐지
- 출처 단위 잭나이프 안정성 분석

가중 최단거리 계산에는 `distance = 1 / weight`를 사용합니다. 가중치는 협력의 질·투입량·독립 출처 수를 의미하지 않습니다.

## 주요 관측 결과

| 지표 | 선정 이전 | 선정 이후 | 전체 기간 |
|---|---:|---:|---:|
| 기관 수 | 56 | 56 | 56 |
| 활성기관 수 | 14 | 39 | 42 |
| 고유 기관쌍 수 | 12 | 39 | 46 |
| 관계 기록 수 | 12 | 46 | 58 |
| 최대 연결요소의 기관 수 | 4 | 33 | 35 |

기관쌍의 기간별 변화는 다음과 같습니다.

| 분류 | 기관쌍 수 | 의미 |
|---|---:|---|
| `persisted` | 5 | 두 기간 모두 관계 기록이 관측됨 |
| `pre_only` | 7 | 선정 이전에만 관측됨 |
| `newly_observed_during` | 34 | 선정 이후에만 관측됨 |

`newly_observed_during`은 **newly observed after selection**을 뜻합니다. 선정의 인과효과로 해석하지 않습니다. 마찬가지로 `persisted`는 협력의 지속을, `pre_only`는 협력의 종료를 직접 입증하지 않습니다.

## 네트워크 시각화

세 기간의 그림은 동일한 노드 좌표와 전체 기간 degree에 따른 노드 크기를 사용합니다.

- **사각형:** 주관기관
- **노드 색:** 팀 소속
- **빈 노드:** 해당 기간에 연결이 관측되지 않은 기관
- **선 두께:** 해당 기간 관계 기록 수에 따른 로그 척도
- **오른쪽 별도 영역:** 전체 기간에 연결이 관측되지 않은 기관

배치상의 거리와 군집 형태는 성과·지리적 거리·인과효과를 의미하지 않습니다.

## Walktrap 군집화

전체 기간의 협력망에 가중 Walktrap을 적용합니다.

- 구현: Python `igraph`
- 보행 길이: `steps = 4`
- 가중치: 기관쌍별 관계 기록 수
- 분할 기준: 병합 과정에서 모듈성이 최대가 되는 분할
- 고립기관: 실질 군집에 할당하지 않고 별도 표시

현재 데이터에서 활성기관 42개는 **5개 군집**으로 분할됩니다. 군집 크기는 **13·9·7·7·6개**, 가중 모듈성은 **Q ≈ 0.6718**입니다.

이 그림의 색은 팀 소속이 아닌 **탐지된 군집**을 의미합니다. 점선 경계와 옅은 배경은 군집을 나타내는 시각적 주석이며 협력 edge가 아닙니다. 일부 경계 영역은 겹칠 수 있으나 중복 군집 소속을 뜻하지 않습니다.

## 잭나이프 안정성 분석

출처 묶음을 하나씩 제외하고 네트워크를 다시 계산하는 **출처 단위 삭제 민감도 분석**을 수행합니다.

동일 URL을 공유하는 출처 ID는 하나의 묶음으로 처리합니다. 현재는 S015·S016을 함께 묶어 총 **31개 출처 묶음**을 사용하며, 세 기간에 각각 31회씩 **총 93회** 계산합니다.

각 반복에서 기관 집합은 고정하고 남은 관계 기록으로 가중치를 다시 집계합니다. 새로운 기관쌍은 생성하지 않습니다.

### 확인하는 항목

- 고유 edge 수, 밀도, 연결요소, 최대 연결요소의 변화
- 비주관기관 간 수평 edge 비율의 변화
- 기관별 중심성과 순위의 변동 범위
- Walktrap 군집 수·모듈성·원래 분할과의 일치도

군집 일치도는 **조정 랜드 지수(ARI)**로 측정합니다. 각 기간의 원래 활성기관 집합을 고정하며, 출처 제거로 고립된 기관은 각각 독립된 singleton으로 처리합니다.

전체 기간에서 S012를 제외할 때 고유 관계 6개가 사라져 가장 큰 관계 손실이 나타났습니다. ARI의 최솟값은 전체 기간 약 **0.795**, 선정 이후 약 **0.719**입니다.

이 분석의 최솟값–최댓값은 **관측 출처 제거에 대한 민감도 범위이며 모집단 신뢰구간이 아닙니다.**

## 실행 방법

Python과 다음 패키지가 필요합니다.

```bash
pip install pandas numpy networkx matplotlib scipy tabulate igraph
```

프로젝트 루트에서 실행합니다.

```bash
python "기관쌍_협력망_분석.py"
```

기본 입력·출력 경로는 스크립트 위치를 기준으로 합니다. 다른 경로도 지정할 수 있습니다.

```bash
python "기관쌍_협력망_분석.py" --data-dir data --output-dir output
```

한글 표시는 기본적으로 Windows의 `Malgun Gothic` 폰트를 사용합니다. 다른 운영체제에서는 코드의 폰트 설정을 사용 가능한 한글 폰트로 변경해야 합니다.

## 향후 역량 분석 연계

R 텍스트 분석 결과를 결합할 수 있도록 다음 7개 역량 컬럼을 제공합니다.

```text
cap_infra_compute
cap_data
cap_model_pretraining
cap_posttraining_alignment
cap_reasoning_safety_eval
cap_deployment_optimization
cap_application_service
```

현재 값은 모두 빈칸이며 임의 점수를 생성하지 않습니다. 연구자가 공통 척도로 값을 채운 뒤 명시적으로 입력 파일을 지정했을 때만 다음을 계산합니다.

- Cosine similarity
- Dominant capability
- 기존 협력 edge의 cross-capability linkage
- Team capability coverage

```bash
python "기관쌍_협력망_분석.py" --capability-profile filled_capabilities.csv
```

역량 유사도는 기관의 속성 비교이며 새로운 협력 edge로 전환하지 않습니다.

## 해석상의 한계

- 공개자료의 보도·공시 선택편향으로 일부 기관과 협력이 과대표집될 수 있습니다.
- **미관측 edge는 실제 협력관계의 부재를 의미하지 않습니다.**
- 입력 CSV의 직접협업 근거를 분석에 사용하며, 실행 과정에서 원문 자료를 독립적으로 재검증하지 않습니다.
- 동일 발표에서 나온 관계 기록은 서로 의존할 수 있습니다.
- 선정 전후 관측 기간의 길이와 공개 관행 차이를 통제하지 않습니다.
- 팀 소속은 제공된 정적 메타데이터이며 과거 시점의 소속을 복원한 결과가 아닙니다.
- 군집 탐지와 잭나이프는 해당 관측자료와 분석 설정에 조건부인 결과입니다.
- 본 분석은 **선정 전후에 관측되는 협력구조를 기술하는 분석**이며, 독파모 선정이나 DARPA형 구성의 인과효과를 추정하지 않습니다.
